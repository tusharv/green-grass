Under the Hood

Code Decides Fit, Not an LLM Guess.

Suitability is calculated by a deterministic Python engine (app/services/fit.py), never delegated to model hallucinations:

Math Formula

Scoring in Python

score = round(100 * (0.7 * coverage + 0.3 * years_score))

A candidate is suitable only when required skills exist and the calculated score exceeds 60. Math decides, never a prompt.

Evidence Match

Contiguous Quotes

A skill only counts if the engine quotes a contiguous excerpt of at least 40 characters from the CV's work history. Sibling tools never count (Angular never proves React).

Seniority Math

Industry Floors

Experience years are checked against strict seniority floors: Junior 0, Mid 3, Senior 5, Lead/Staff 8, Principal 10. Missing CV dates count as 0.
